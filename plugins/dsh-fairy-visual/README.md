# dsh-fairy-visual

Fairy 风格的 DeepSeek Harness 界面插件：动态大眼睛、渐变背景、快捷控件与流式对话滚动保护。

版本：`1.1.0`。已验证 DeepSeek Harness `0.2.0-rc.2`，Windows x64 / web profile。

## 安装与使用

请从 [Releases](https://github.com/FLKSSSSS/Fairy/releases/tag/plugins-v1.1.0) 下载同名 `.tgz`，或下载三插件合集。详细安装方式见[仓库首页](../../README.md)和[使用说明](../../docs/使用说明.txt)。

## 代码与发行包

此目录保存发行包中的运行代码、资源、类型声明和 DSH bundle 配置；不包含第三方 `node_modules`、Electron 二进制和语音模型。它不是完整的原始 TypeScript 工程。仅复制目录或下载 GitHub Source code ZIP 不等于安装完成，请使用 Releases 的已验证安装包。仓库代码未另行重新构建。

原有详细说明见 [README.txt](README.txt)，来源与许可说明见 [PROVENANCE.txt](PROVENANCE.txt)。
