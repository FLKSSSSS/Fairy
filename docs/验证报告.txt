Fairy 独立插件验证报告
日期：2026-10-09

一、适配范围
DeepSeek Harness 0.2.0-rc.2，Windows x64，web profile。
插件版本 1.1.0。不宣称兼容正式版 0.2.0 或其他版本。

二、已通过
- UI、Voice、Orb、All 四组合独立安装、自动启用、有效 patch、依赖检查，重复 ID 为 0。
- 插件 JavaScript 语法、客户端模块 ID、bundled dependencies、离线 Electron 路径检查。
- 四组合使用 headless Edge 打开真实 DSH 网页，插件真实组合请求 HTTP 200；无页面或控制台错误。
- UI 单装挂载 Fairy 元素 104 个，三插件共装挂载 139 个，样式均存在。
- 安装脚本实际安装、重复安装及元数据备份、旧 Fairy 冲突拒绝、PowerShell 解析。
- 插件包敏感路径及常见密钥模式扫描；语音 ZIP 敏感路径检查。语音依赖内的两个 credentials.py 是库源代码，不是用户凭据文件。
- 语音环境 ZIP 全文件 CRC 与 SHA256 校验。

三、验证限制
- 原动态眼睛、悬停及文本框修复继承已修复代码；本次验证不是完整桌面交互验收。
- 未测试真实 GPU/CPU 合成和音频播放，TTS 状态已 mock；未接触现有语音服务。
- 网页验证确认插件加载和 UI 挂载，不等于完整滚动/动画/自动朗读交互验收。
- Orb 在隔离网页测试中关闭了自动启动，未进行真实桌面鼠标键盘测试。
- 未修改 E:\Fairy 或 F:\fairy音频依赖；未停止或重启用户 Fairy。
- 密钥扫描有明确范围，不等于能识别所有格式的秘密；交付不包含工作/测试 home、日志或用户配置目录。
- pnpm 可能提示 profile 缺少由 DSH 主程序提供的 peer dependencies；本次以四组合实际网页启动通过为准。真正出现 import/启动错误仍需检查主程序依赖和版本。

详细检查记录见同目录“验证报告.json”。插件包校验见 SHA256SUMS.txt。
外层 ZIP 的 CRC/SHA256 另由同名 .zip.sha256 文件记录。
